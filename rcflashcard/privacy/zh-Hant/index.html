RC Flash Card — 隱私權政策

RC Flash Card 會在您的裝置上處理導入的學習文件、提取的文本、卡片和複習歷史記錄。它沒有開發者帳戶系統、廣告或由開發者運營的分析後端。

文件和圖片

您可以選擇要導入的文件或圖片。文本識別在您的裝置上進行，iOS/macOS 使用 Apple 系統框架，Android 使用捆綁的 Google ML Kit 識別模型。從 URL 導入文件會聯繫該網站，該網站會根據其自己的政策接收您請求的 URL 和普通網絡資訊（例如 IP 地址）。

Android ML Kit

ML Kit 會在本地處理識別圖片。另外，Google 描述了 SDK 收集設備和應用資訊、安裝識別符和運作與使用指標。這些指標與圖片和識別的文本不同。請參閱 Google 的 ML Kit 數據披露和 Google 的隱私權政策。

文件、備份和分享

學習庫會儲存在本地。如果您選擇外部備份資料夾，應用程式會將庫的快照寫入該目的地。所選的文件提供者可能會將這些文件遠端儲存。導入的原始文件、提取的文本、圖片、卡片和複習記錄可能包含在備份中。您控制目的地和任何後續分享；文件提供者的權限、安全性和保留政策適用。此版本不提供自動雙向雲端同步。

購買

Apple StoreKit 或 Google Play 處理購買、恢復、付款細節和退款。應用程式使用購買狀態來決定訪問權限。Rizk Corsight 不會收到您的付款卡或商店帳戶憑證。請參閱適用的 Apple 或 Google 隱私政策。

保留和刪除

導入的原始文件和庫數據在刪除個別卡片後可能仍會留在本地應用程式儲存空間中。請使用您平台的控制功能刪除應用程式儲存的數據以清除該本地副本。備份、導出、共享文件和文件提供者持有的副本必須分別刪除。平台購買記錄和 SDK 運作數據遵循平台提供者的保留政策。

支援

如果您透過電子郵件聯繫支援，我們會收到您選擇發送的地址和資訊，並用來回應您的請求。請不要無需必要地傳送敏感學習文件。RC Flash Card 不會要求兒童提供直接聯繫資訊作為其學習功能的一部分。

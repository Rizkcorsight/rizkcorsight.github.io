ภาพถ่ายและการวิเคราะห์

รูปภาพที่คุณเลือกสำหรับการวิเคราะห์ริ้วรอยหรือฉลากการดูแลจะถูกประมวลผลบนอุปกรณ์ของคุณ AIRONY จะไม่อัปโหลดรูปภาพเหล่านั้นไปยังบริการวิเคราะห์ การวิเคราะห์ต้องใช้อุปกรณ์ที่รองรับซึ่งมีรุ่นในอุปกรณ์ที่พร้อมใช้งาน ความพร้อมใช้งานของรุ่นขึ้นอยู่กับระบบปฏิบัติการและอุปกรณ์ ไม่ใช่ทุกอุปกรณ์ที่รองรับการวิเคราะห์

การวินิจฉัยรุ่น Android

บน Android AIRONY ใช้ Google ML Kit และ AICore สำหรับการประมวลผล AI ในพื้นที่ Google เอกสารที่ ML Kit SDK รวบรวมเมตริกทางเทคนิคสำหรับการวินิจฉัยและการวิเคราะห์การใช้งาน ได้แก่ ข้อมูลอุปกรณ์และแอป ตัวระบุ การวัดประสิทธิภาพ การกำหนดค่า API ขนาดอินพุตและเอาต์พุต เหตุการณ์และข้อผิดพลาดของฟีเจอร์ และภาษาที่กำหนดค่า Google ระบุว่าการวัดเหล่านี้ได้รับการเข้ารหัสระหว่างการส่งผ่านโดยใช้ HTTPS และไม่ได้ถ่ายโอนไปยังบุคคลที่สาม คอลเลกชันการวัดนี้แยกจากการประมวลผลรูปภาพของคุณบนอุปกรณ์ ดูการเปิดเผยข้อมูล ML Kit ของ Google สำหรับรายละเอียด

บันทึกและการสำรองข้อมูลที่บันทึกไว้

รูปภาพ ผลลัพธ์ บันทึกตู้เสื้อผ้า และการตั้งค่าที่บันทึกไว้จะถูกจัดเก็บไว้ในอุปกรณ์ของคุณ การส่งออกข้อมูลสำรองหรือการแชร์ผลลัพธ์จะส่งสำเนานั้นไปยังปลายทางที่คุณเลือก สำเนาที่ถือโดยแอป ผู้รับ หรือการสำรองข้อมูลอุปกรณ์อื่นจะยังคงอยู่ภายใต้การควบคุมของปลายทางนั้น คุณสามารถลบบันทึกที่บันทึกไว้ใน AIRONY การนำแอปออกอาจไม่ลบข้อมูลสำรองของอุปกรณ์ สำเนาที่แชร์ หรือบันทึกการเข้าถึงที่ปลอดภัย
